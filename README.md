# Grimoire Clash

A pixel-art 2D fighting game with 15 original mages, each with its own magic, gauge and signature mechanic.
Runs in the browser — no install.

**Play:** https://lavan123456.github.io/grimoire-clash/

## Modes
- **1P vs CPU** — the CPU levels up every round you win.
- **2P same keyboard**
- **Online vs friend** — *Create room* gives you a 5-letter code (and a link). Your friend opens the link or picks *Online → Join* and types the code.
- **CPU vs CPU**

## Controls
WASD / arrows move · J light · K heavy · L special · U special 2 · I super (1 bar) · O ULTIMATE (3 bars) · P magic burst
Double-tap = dash · up in the air = double jump · down+K = launcher · tap forward as a hit lands = parry · V = art style
